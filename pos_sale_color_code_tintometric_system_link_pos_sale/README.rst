Link between ‘pos_sale_colour_code_tintometric_system’ and ‘pos_sale’ to
ensure that when a sales order is transferred to the POS, the
'Lot/S.Tin' field from pos.order.line is received.

Usage
=====

1. Do a sale order by filling in the ‘Lot/S.Tin’ field.
2. On the order screen select 'Quotation/Order' button |pos_orderline|
3. Select the sale order created and settle the order
