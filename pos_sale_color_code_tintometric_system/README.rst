Usage
=====

1. When a sale order is doing from the point of sale, new button
   'Lot/S.Tin' is available |pos_orderline|
2. This field also appears on the receipt screen |pos_receipt|
3. If we view the order from Point of Sale/Orders/Orders |pos_order|
4. And when the order is invoiced |account_move|
